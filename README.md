# Namaste3D Book

This book guides you through the step-by-step construction of a CPU based software rasterizer and is expected to be an introduction to real-time 3D graphics programmng.

Before 3D graphics accelerator chips were invented, software rendering was the norm. All parts of the 3D pipeline were implemented in software using CPU.

This book touches enough parts of that to get the reader familiar with transformations, viewing, projection, clipping, rasterization, texture mapping, lighting, shading and depth buffering.

Each chapter is in the form of a problem and its solution presenting only necessary algorithm or code.

The reader can make his own implementation and or read the accompanying source code.
